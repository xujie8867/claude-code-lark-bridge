# Roadmap

This document outlines the planned development direction for Claude Code Lark Bridge.

## Short-term (Next 30 Days)

- [ ] GitHub Actions CI/CD pipeline for skill validation
- [ ] Automated weekly release workflow
- [ ] Add test coverage for core skills (im, base, calendar)
- [ ] Improve error messages across all skills
- [ ] Add bilingual (zh/en) descriptions for all skills

## Medium-term (Next 60 Days)

- [ ] Web-based skill configuration dashboard
- [ ] Skill dependency graph visualization
- [ ] Automated Lark API version compatibility checks
- [ ] Performance benchmarks for high-frequency skills
- [ ] Community-contributed skill templates

## Long-term

- [ ] Multi-language skill support (Japanese, Korean)
- [ ] Plugin system for third-party skill extensions
- [ ] Integration with other AI coding assistants
- [ ] Enterprise-grade monitoring and logging
- [ ] Managed cloud service for skill hosting
