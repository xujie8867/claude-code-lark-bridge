### Added

- Initial release with 26 Lark/Feishu Skills for Claude Code

- Skills included: Slides, Markdown, Apps (Miaoda), Attendance, Event
- Skills included: OpenAPI Explorer, Skill Maker, Whiteboard
- Skills included: Workflow Meeting Summary, Workflow Standup Report
- Skills included: Shared (Auth & Setup)
- Comprehensive README with architecture diagram and usage examples
- MIT License
- Support for macOS, Linux, and Windows
- Bot and User identity modes
- Email templates (newsletter, weekly report, job application, market report)
- Detailed references for lark-mail operations
