# Standup Report Workflow — Usage Guide

## Overview
Generates a daily standup summary combining calendar agenda and pending tasks.

## Quick Start
```bash
lark-cli workflow-standup-report +generate --date 2026-06-11
```

## What It Shows
- **Today's Schedule**: Upcoming meetings and events
- **Pending Tasks**: Unfinished tasks assigned to you
- **Overdue Items**: Tasks past their due date
- **Focus Areas**: Suggested priorities for the day

## Tips
- Run each morning for daily planning
- Combine with lark-calendar +agenda for quick calendar overview
- Use lark-task +get-my-tasks for detailed task breakdowns
